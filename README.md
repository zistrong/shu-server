# shu-server
这位老哥 https://github.com/dooshu/shu 的图书的server端
## 如何使用
### 前置
需要安装docker， docker-compose
### 启动server
1. 将本程序clone到上面的老哥的shu的同级目录下
2. 执行 docker-compose up -d（第一次较慢， 需要下载一些镜像）
3. 打开 http://your-ip:8000/
4. 愉快的阅读吧， 享受阅读的乐趣。
## 功能列表
1. 按照书库展示图书列表
2. 注册、登录
3. 记录阅读进度， 阅读时长
4. 删除阅读记录
5. 图书标签，记录精彩片段
6. 统计读书时长
